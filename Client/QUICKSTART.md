# Швидкий старт - Авторизація та Чекаут

## ✅ Все готово до використання!

### Що було зроблено:

1. **Захищені маршрути** - всі сторінки окрім `/login` та `/register` доступні тільки авторизованим користувачам
2. **Кнопка "Замовити"** в корзині - веде на сторінку чекауту
3. **Інформація про користувача** в хедері + кнопка виходу
4. **Персональна корзина** для кожного користувача

### Як тестувати:

#### 1. Запустити проект
```bash
cd назаренко
npm start
```

#### 2. При першому відкритті
- Ви будете автоматично перенаправлені на `/login`
- Натисніть "Зареєструватися" внизу форми

#### 3. Реєстрація
- Заповніть всі поля (ім'я, прізвище, email, пароль)
- Email має бути правильного формату (наприклад: `user@example.com`)
- Пароль мінімум 6 символів
- Після успішної реєстрації ви потрапите на головну

#### 4. Використання
- Додайте товари в корзину
- Перейдіть в корзину (`/cart`)
- Натисніть кнопку **"Замовити"**
- Заповніть форму або натисніть **"Мої дані"** для автозаповнення
- Завершіть замовлення

#### 5. Вихід і повторний вхід
- Натисніть "Вийти" в хедері
- Ви будете перенаправлені на `/login`
- Увійдіть з тими ж даними
- Ваша корзина відновиться автоматично

### Структура маршрутів:

**Публічні (доступні всім):**
- `/login` - Вхід
- `/register` - Реєстрація

**Захищені (тільки для авторизованих):**
- `/` - Головна сторінка
- `/items` - Каталог товарів
- `/items/:id` - Деталі товару
- `/cart` - Корзина
- `/checkout` - Оформлення замовлення
- `/success` - Успішне замовлення

### Де знаходяться дані:

Всі дані зберігаються в `localStorage`:
- `mock_users` - всі зареєстровані користувачі
- `redux_user` - поточний користувач
- `redux_cart_{userId}` - корзина користувача
- `order` - останнє замовлення

### Можливі проблеми:

**"Не можу увійти"**
- Переконайтеся, що ви спочатку зареєструвалися
- Перевірте правильність email та паролю
- Email повинен мати формат `user@example.com` (мінімум 2 символи після крапки)

**"Корзина пропала"**
- Це не повинно траплятися, але якщо трапилося - очистіть localStorage (`F12` → Application → Local Storage → Clear All) і зареєструйтеся знову

**"Помилка при замовленні"**
- Переконайтеся, що в корзині є товари
- Всі поля форми мають бути заповнені правильно
- Телефон: рівно 10 цифр
